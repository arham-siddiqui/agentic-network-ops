Event log
    Security boundaries
    • The investigator runs on the host and reads Prometheus through 21 fixed, read-only queries. It has no shell, Docker, or fault tools.
    • Fault controls sit on a separate internal control network and are reached only from an operator terminal over Unix sockets (make inject-network-fault, make inject-cpu-fault, make worker-outage). There is no HTTP fault endpoint.
    • Fault markers and scenario records are ground truth for evaluation only; they are never inputs to alerts or diagnosis.
    • Containers run non-root with dropped capabilities, read-only filesystems, CPU/memory limits, and no outbound internet.
    How this works 

    make inject-network-fault                 # latency, 600 ms, 60 s
make inject-network-fault LATENCY_MS=900
make inject-network-fault SCENARIO=timeout
make inject-cpu-fault
make worker-outage DURATION=30             # stops, then restarts the worker
make stop-network-fault
make investigate                          # real investigator report
    agentic-network-ops · simulation timings are assumptions; thresholds, limits and diagnosis logic follow the repository.
